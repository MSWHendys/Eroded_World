# Eroded World

**A hardcore survival overhaul for Minecraft Fabric.**

*The world remembers your actions and reacts to your decisions.*

Eroded World transforms Minecraft survival into a more challenging experience. Mining destabilizes the underground, darkness becomes dangerous, energy affects survival, and the environment responds to player activity.

## Minecraft Versions & Source Code

Eroded World is developed for multiple Minecraft versions.

**This branch contains the general project overview. Source code and version-specific build instructions are maintained in separate branches.**

[Browse all source branches](https://github.com/MSWHendys/Eroded_World/branches)

Each version branch contains its own source files, dependencies, installation requirements, and technical README.

## Main Features

- **Energy & Stamina** – Physical actions consume energy.
- **Mining & Cave-ins** – Underground activity can destabilize tunnels.
- **True Darkness** – Darkness becomes a survival threat.
- **Dynamic Ecosystem** – The world reacts to environmental damage.
- **Crafting Quality** – Equipment quality affects progression.
- **Territory Protection** – Protect player bases and territory.
- **Death Recovery** – Recover lost equipment using special tools.
- **Dangerous Enemies** – Hostile creatures react to environmental conditions.
